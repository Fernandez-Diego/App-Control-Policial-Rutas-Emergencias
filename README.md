## 📌 Nota Institucional y Guía de Uso Rápido

### 🏛️ Marco Institucional
En el marco de la estructura organizativa del **Ministerio de Seguridad y Justicia de la Provincia de Mendoza**, la máxima autoridad policial es la **Dirección General de Policía**. Por ello, el desarrollo y propuesta de evaluación de esta herramienta web están orientados a su tramitación y declaración de *Interés Didáctico y Operativo* ante dicha Dirección General.

---

### 🚀 ¿Cómo funciona la aplicación? (Guía Sencilla)

Esta Aplicación Web Progresiva (PWA) está diseñada como una **herramienta táctica de bolsillo** para el efectivo policial que se encuentra prestando servicio en rutas, controles vehiculares y puestos camineros.

1. **Sin instalaciones complejas:** Se abre directamente desde el navegador del celular (Chrome, Safari, Edge) escaneando el código QR o ingresando al enlace web.
2. **Alertas y Emergencias Viales (Acceso Inmediato):** Ante un accidente con camiones cisterna o derrames químicos, el policía cuenta con un protocolo visual rápido con distancias de seguridad (100 m a 800 m en riesgo BLEVE), pautas de aislamiento y números de emergencia.
3. **Control de Cargas y Minerales:** Permite verificar rápidamente las **Guías de Tránsito de Minerales (código QR)** y consultar la lista de sustancias restringidas por la Ley N.º 7.722 y el Código de Procedimiento Minero (Ley N.º 9.529).
4. **Bloc de Notas Táctico:** Permite anotar temporalmente patentes, datos del chofer, tipo de carga y novedades del puesto caminero. La información se guarda de forma privada en la memoria local del teléfono (`localStorage`), por lo que no consume datos adicionales ni se pierde si se cierra el navegador.
5. **Próxima versión (Offline total):** Pensada para zonas de alta montaña o con baja cobertura de señal mediante Service Workers.
